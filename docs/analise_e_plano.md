# Tema 12 — PIB Brasileiro: análise e plano do dashboard

**Aluno:** Evandro Miguel · **Turma:** 1 · **Apresentação:** 17/11/2026
**Pergunta norteadora:** Como o PIB brasileiro evoluiu e como os principais setores participaram desse desempenho?

---

## 1. Resposta curta

O PIB brasileiro cresceu **2,26% ao ano em termos reais entre 2000 e 2025** (+74,9% no
período). Os **serviços** são o maior setor (69,5% do valor adicionado em 2025) e a
principal fonte de crescimento; a **agropecuária** é o setor que mais cresce (3,71% a.a.),
embora tenha participação menor; a **indústria** perdeu espaço (26,7% → 23,4% do valor
adicionado) e cresceu apenas 1,30% a.a. Em 2026, o crescimento segue positivo, mas
concentrado em agropecuária, indústrias extrativas e informação/comunicação, com a
indústria de transformação em queda.

- Serviços: +1,25 p.p.; agropecuária: +0,78 p.p.; indústria: +0,35 p.p.

### 2.5 Três achados para a apresentação

1. **Serviços sustentam o crescimento e concentram 69,5% do valor adicionado.** É o setor
   decisivo para o nível de atividade, mas cresce a taxas moderadas (2,41% a.a. no longo prazo).
2. **A agropecuária é pequena em participação (7,1%), porém a mais dinâmica (3,71% a.a.)** e
   explica 0,78 p.p. do crescimento de 2025; em 2026-T2, cresce 6,8%.
3. **A indústria perde participação e a transformação está estagnada.** A indústria caiu de
   26,7% para 23,4% do valor adicionado em 25 anos; em 2026-T2, a transformação recua 0,9%,
   enquanto a extrativa cresce 12,0%. O crescimento recente é concentrado em poucos setores.

## 3. Modelo de dados sugerido (Power BI)

Modelo em estrela, com duas dimensões compartilhadas e quatro fatos separados por unidade:

```
dim_tempo (1) ──< (*) fato_pib_volume
dim_tempo (1) ──< (*) fato_pib_volume_sazonal
dim_tempo (1) ──< (*) fato_pib_corrente
dim_tempo (1) ──< (*) fato_pib_taxa

dim_serie (1) ──< (*) fato_pib_volume
dim_serie (1) ──< (*) fato_pib_volume_sazonal
dim_serie (1) ──< (*) fato_pib_corrente
dim_serie (1) ──< (*) fato_pib_taxa
```

**Por que quatro fatos e não um só:** as unidades são diferentes (índice, %, R$ milhões).
Empilhar tudo em uma única coluna `valor` mistura grandezas e permite somas sem sentido.
Separar preserva a semântica e evita erros de agregação.

**Chaves:** `dim_tempo[data]` e `dim_serie[serie]`. Marcar `dim_tempo` como tabela de datas.
Relacionamentos 1:* com filtro simples (direção única).

**Colunas úteis em `dim_tempo`:** `data`, `ano`, `trimestre`, `trimestre_txt`,
`ano_trimestre`. Se quiser, acrescentar `decada` e `is_ultimo_trimestre`.

**Colunas úteis em `dim_serie`:** `serie`, `grupo`, `subgrupo`, `nivel` (Setor, Subsetor,
Agregado, Componente), `ordem`. Use `ordem` para ordenar visuais e `nivel` para
segmentadores hierárquicos.

## 4. Medidas DAX essenciais

> **Atualizado em 23/10/2026:** estas medidas foram substituídas pela versão corrigida em
> [`docs/medidas_dax.md`](medidas_dax.md). O bloco abaixo fica como registro do processo;
> **não use estas versões no Power BI** — elas têm quatro defeitos descritos na seção
> "O que mudou e por quê" do arquivo novo.

> Ajuste os nomes se o modelo usar outros nomes de tabela/coluna.

```dax
PIB real (índice) =
CALCULATE(
    AVERAGE(fato_pib_volume[valor]),
    dim_serie[serie] = "PIB a preços de mercado"
)
```

```dax
PIB real YoY % =
VAR atual = [PIB real (índice)]
VAR anterior =
    CALCULATE([PIB real (índice)], SAMEPERIODLASTYEAR(dim_tempo[data]))
RETURN DIVIDE(atual - anterior, anterior)
```

```dax
PIB real QoQ % (sazonal) =
VAR atual =
    CALCULATE(
        AVERAGE(fato_pib_volume_sazonal[valor]),
        dim_serie[serie] = "PIB a preços de mercado"
    )
VAR anterior =
    CALCULATE(
        AVERAGE(fato_pib_volume_sazonal[valor]),
        dim_serie[serie] = "PIB a preços de mercado",
        DATEADD(dim_tempo[data], -1, QUARTER)
    )
RETURN DIVIDE(atual - anterior, anterior)
```

```dax
PIB nominal (R$) =
CALCULATE(
    SUM(fato_pib_corrente[valor]),
    dim_serie[serie] = "PIB a preços de mercado"
) * 1000000
```

```dax
Participação no VA % =
VAR setor = SUM(fato_pib_corrente[valor])
VAR va =
    CALCULATE(
        SUM(fato_pib_corrente[valor]),
        dim_serie[serie] = "Valor adicionado a preços básicos"
    )
RETURN DIVIDE(setor, va)
```

```dax
Contribuição ao crescimento (p.p.) =
VAR crescimento = AVERAGE(fato_pib_taxa[valor]) / 100
VAR peso =
    DIVIDE(
        CALCULATE(
            SUM(fato_pib_corrente[valor]),
            SAMEPERIODLASTYEAR(dim_tempo[data])
        ),
        CALCULATE(
            SUM(fato_pib_corrente[valor]),
            dim_serie[serie] = "Valor adicionado a preços básicos",
            SAMEPERIODLASTYEAR(dim_tempo[data])
        )
    )
RETURN crescimento * peso * 100
```

```dax
CAGR 2000–2025 =
VAR inicio =
    CALCULATE(
        AVERAGE(fato_pib_volume[valor]),
        dim_serie[serie] = "PIB a preços de mercado",
        dim_tempo[ano] = 2000
    )
VAR fim =
    CALCULATE(
        AVERAGE(fato_pib_volume[valor]),
        dim_serie[serie] = "PIB a preços de mercado",
        dim_tempo[ano] = 2025
    )
RETURN (fim / inicio) ^ (1 / 25) - 1
```

```dax
Média móvel 4T (índice) =
CALCULATE(
    AVERAGE(fato_pib_volume[valor]),
    DATESINPERIOD(dim_tempo[data], MAX(dim_tempo[data]), -4, QUARTER)
)
```

**Validação:** confira as medidas contra os valores da tabela 5932 (YoY) e contra os
números deste documento. Se divergirem, verifique o contexto de filtro e a série
selecionada.

## 7. Cuidados metodológicos (para a documentação)

- **2026 é parcial:** só há 1º e 2º trimestres; não calcular crescimento anual de 2026.
- **Nominal × real:** 1846 é preços correntes; 1620/1621 são volume. Não misturar.
- **1621 é ajustada sazonalmente:** usar para QoQ; não somar com a 1620.
- **5932:** foi usada a taxa trimestral contra o mesmo trimestre do ano anterior. As outras
  opções (acumulada em 4 trimestres e acumulada no ano) não foram carregadas para evitar
  duplicidade de métricas.
- **Séries diferentes entre tabelas:** 1620/5932 = 22 séries; 1621 = 21; 1846 = 23. Ao
  cruzar, use `dim_serie` e trate ausências.
- **Variação de estoque** pode ser negativa e volátil; não interpretar como participação.
- **Revisões do IBGE:** os dados podem ser revisados; registrar a data de acesso e
  reexecutar o ETL.
- **Não somar índices nem percentuais:** somas só fazem sentido em R$ correntes.
